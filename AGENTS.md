# HakiOS A51 source work package

Read README.md, docs/PUBLIC-STATUS.md, docs/PUBLICATION.md, docs/PUBLIC-BUILD.md,
docs/INDEX.md, docs/IMPLEMENTATION-LOG.md and docs/ROADMAP.md before work.

Keep source audits, host/native models, QEMU, original device evidence and user
screen reports distinct. Phase 4 is incomplete. V2's user-reported home screen
does not qualify GPU acceleration, audio, Safari or Apple services. V3 device
audio/Iris acceptance is pending. Preserve failed attempts and rollback evidence.

Keep proprietary runtime/SDK material, vendor firmware, backups, personal raw
logs and generated binaries out of commits. Preserve licenses and attribution.
Record implementation/configuration changes, verification, limits and rollback
in docs/IMPLEMENTATION-LOG.md. Use scripts/run.py for consequential commands.
Historical scripts contain workspace-specific paths and device hashes; configure
and verify these before reuse. Source publication is not hardware qualification.

User instructions override these guidelines; do not invent additional approvals.
